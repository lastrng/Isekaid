## Architecture actuelle

Les nouveaux domaines sont isolés dans `src/features`, `src/entities` et
`src/services`. Les modèles testables couvrent notamment le voyage, le profil,
le mode Japon, le Readiness Score, les recommandations, les contenus liés,
l'offline et la synchronisation. `src/App.jsx` reste toutefois un point central
important (environ 8 700 lignes) ; son extraction progressive demeure le chantier
technique principal.

## Sécurité et données

Les validations de fichiers, URLs et entrées serveur sont en place. Les Edge
Functions vérifient l'identité et le statut Premium côté serveur, appliquent les
quotas et gardent les secrets côté serveur. Les données locales restent la source
de continuité hors connexion ; les synchronisations sont protégées par fusion et
file de mutations.
